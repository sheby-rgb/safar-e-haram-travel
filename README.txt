SAFAR-E-HARAM TRAVEL AND TOURS — COMPLETE FREE WEBSITE STARTER

WHAT IS INCLUDED
- index.html: full responsive multi-section website
- assets/style.css: premium emerald-green and royal-gold styling
- assets/app.js: inquiry form, quick inquiry helper, FAQ accordion and Safar AI FAQ chatbot
- assets/logo.svg: original editable vector logo created for this website
- assets/favicon.svg: matching browser icon

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome, Edge or Firefox.
3. Keep the assets folder next to index.html; do not move it separately.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a public repository, e.g. safar-e-haram.
2. Upload index.html and the complete assets folder (including both SVG files).
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Later you can connect your own domain in Settings -> Pages -> Custom domain.

FREE DEMO LIMITATIONS — PLEASE READ
This is a static HTML/CSS/JavaScript website designed to run free on GitHub Pages.
- Inquiry form opens WhatsApp with a prepared message; the customer must press Send. It does not save inquiries to a server.
- Safar AI is a built-in FAQ chatbot with prepared answers in Urdu/English. It is not a generative ChatGPT model and has no live access to embassy rules, flight fares, hotel inventory or bookings.
- No secure customer accounts, admin dashboard, server database, payment processing or live flight/hotel booking engine are included in this static package.
- Never place a private AI API key or payment secret in public JavaScript. Real AI, secure login, admin dashboard, saved inquiries and online payments require a secure backend and suitable provider integrations.
- Visa outcomes are decided by the relevant authority; no approval should be promised or guaranteed.

EDITING
Edit index.html for page text, assets/style.css for colors/layout, assets/app.js for WhatsApp number and chatbot replies, and assets/logo.svg for the logo. Re-upload changed files to GitHub to publish updates.
